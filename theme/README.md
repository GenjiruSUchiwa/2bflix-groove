# Thème Jellyfin

En cours de développement. Le thème ciblera Jellyfin web 12.1 :

- `groove.css` : CSS personnalisé (Préférences > Affichage > CSS personnalisé, ou marque du serveur) ;
- `groove.js` : script injecté avec le plugin JavaScript Injector, actif seulement quand `groove.css` est chargé.
